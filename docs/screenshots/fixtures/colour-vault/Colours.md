# Colours in a note

Plain `==highlight==` is ==yellowish==, and the toolbar's colours are <mark style="background: #FFFF00;">neon yellow</mark>, <mark style="background: #39FF14;">neon green</mark>, <mark style="background: #00FFFF;">cyan</mark> and <mark style="background: #FF00FF;">magenta</mark>.

Text can be <span style="color: #E53E3E;">red</span>, <span style="color: #F08A1C;">orange</span>, <span style="color: #2F80ED;">blue</span> or <span style="color: #2EA04F;">green</span>, and both **combine**: <mark style="background: #FFFF00;"><span style="color: #8E4BD6;">purple on yellow</span></mark>.

- [ ] Select some text, then pick a colour in the toolbar above
- [x] Everything is saved as plain HTML tags that other markdown apps understand

> The same note in the reading view and in the PDF export shows the colours too.
