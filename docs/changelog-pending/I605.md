### Added

- A board can be exported through a LaTeX template too: the export dialog of a board has the **LaTeX template** engine, which writes the board on landscape pages (`pdflscape`, lanes as columns of cards), then the notes of the cards as parts (lanes) and chapters (cards) of a thesis or report, with the contents (#605). The TeX Live package `pdflscape` is now part of the managed install and the check of a system TeX.
