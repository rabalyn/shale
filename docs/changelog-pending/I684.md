### Fixed

- Uploading pictures, videos and calendar events failed on Windows with "the file cannot be sent (its name or type has special characters)": the check refused the backslash of every Windows path; backslashes are now allowed (and escaped for curl), while quotes, semicolons, commas and control characters stay refused (#684).
- On Windows, a font given as `/path/Font.ttf` in a note's `print-font` is refused as outside the vault, as on other systems, and the demo pictures of the social feed (absolute Windows paths) open in the viewer instead of being fetched as addresses (Refs #684).
- On Windows, the backlinks and the board of a published page are found again: the page's path is looked up with `/`, not with the backslashes Hugo uses there (Refs #684).
