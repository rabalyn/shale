### Added

- Boards: blockers can be set and removed from the board view. The peek of a card lists **Blocked by** and **Blocks** with a ✕ on each, and has **+ Add blocker** and **+ Add blocked card** fields that find notes through the search worker (cards of the board first). The selected card has a link handle: drag it onto another card ("A blocks B" while dragging, Esc cancels), and a right click on a card has **Add blocker…**, **Add blocked card…** and **Remove blocker ▸**. The waiting note's `blocked-by:` is changed in place (other blockers and lines stay, `modified:` stays, one undo step, the last blocker takes the line with it); a card cannot block itself, a blocker is not added twice, and one that closes a cycle is allowed with a hint. `blocked-by:` also reads markdown links, so a note called "Mail #12" can be a blocker (#677).
