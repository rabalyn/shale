### Added

- **One file and folder picker for the whole of Shale**: Open…, Create… and Locate… for a vault, the library folders, the import of a template set and the logos of the LaTeX export, the attachments of a mail and the place of a PDF export now choose with the dialog of your system (the xdg-desktop-portal on Linux, the native dialog of Windows and macOS), which has its own shortcuts, search and New folder button. Where there is none, or when you turn **Use the system's file dialog** off (Settings → Vault), Shale's own picker opens: a path field, shortcuts to your home folder, Desktop, Documents, Downloads, Pictures, Videos and Music, your vaults, your library folders and your drives, folders and files, several files at once, kinds of file, and a **New folder** field that makes a folder inside the shown one and uses it (a name Windows would not accept is refused with the reason; a name that exists offers to use that folder). The **Import** dialog has an **Add files…** button for several files at once, with the kinds of the import as filters; the typed path stays (#690, #688).

### Changed

- Create… with the system's dialog makes an empty vault; the box "Start with sample notes" is in Shale's own picker.
