### Changed

- **The PDF export uses the column widths and row heights stored with a table.** Sizes you set
  by dragging a grid's borders are now used in the PDF: the widths in proportion across the
  page's text width (every column at least 24 points), a stored row height as the least height of
  its row. A table whose sizes do not match falls back to the automatic widths (EDIT-031,
  PDF-001; raba/shale#238).
