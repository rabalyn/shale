### Added

- A vault can be written as a Hugo website: `shale export-site <vault> <out>` (with `--dry-run` to list what it would write) writes the notes the vault's publishing rules choose as a complete Hugo site, with the Shale theme, backlinks, tags, typeset math and a search box for Pagefind. Publishing is off until `publish.enabled` is set in the vault's `.shale/settings.json`; nothing of a note that is not chosen, no hidden file, conflict copy or mail original is ever written, and the vault is never changed. The Settings page for the rules and the push to a server follow (#630).
