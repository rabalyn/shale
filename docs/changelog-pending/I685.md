### Fixed

- Running the tests no longer overwrites your real settings file (`~/.config/shale/config.toml`: the last vault and the list of known vaults), data, caches or secrets: in a test build every folder of the user is a folder of the test process, and a landing runs the tests with empty XDG folders and fails when something is written there (Closes #685).
  If your last vault was lost on 2026-11-25, open it again and add the other vaults again (or restore the settings file from a backup or file history).
