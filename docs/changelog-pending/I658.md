### Added

- The **LaTeX export now uses the fonts you name**: `print-font`, `print-font-sans` and `print-font-mono` of a note, `font`, `font_sans` and `font_mono` in a template set's `settings.toml`, and the vault's `print_font*` settings override the template's text, sans and code fonts. A family of the vault's `fonts/` folder is copied into the export with its bold and italic faces, an installed font or a font of TeX Live is passed by name, and a font whose licence forbids embedding is not used. A font that TeX cannot find is a warning, not a failed export: the template's font is used and the document is compiled once more. A book uses one font, the top folder note's; the emoji keep their own font (#658).
