### Added

- **Font fields in the export dialog and in Settings** (#658): the export dialog of a note or a folder has a *Fonts* row with the text, headings and code fonts. They start with what the note (a folder's: its top note) says and can be changed for this export: pick a family from the list of the fonts found on the computer and in the vault's `fonts/` folder, or type a name or a vault path. The dialog says which font each part gets and why one cannot be used. Settings → Vault has the same fields for the whole vault (*Fonts of the exports*, with a status under each value) and a button *Look up fonts again* for a font installed while Shale runs. The font list is looked up in the background.

### Changed

- The line *From the note* of the export dialog no longer names the note's font: the font fields show it.
