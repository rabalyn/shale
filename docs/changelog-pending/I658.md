### Added

- The export dialog of a note now has a **Fonts** row: when the note (`print-font`, `print-font-sans`, `print-font-mono`) or the vault's settings (`print_font`, `print_font_sans`, `print_font_mono` in `.shale/settings.json`) name a font, it says which one the export would use and where it was found (the vault's `fonts/` folder or an installed font), and warns when a font is missing or its licence does not allow embedding it. The fonts are looked up in the background (#658). The exports themselves do not use them yet.
