Back to [[Start here]]. Every feature of Shale from A to Z, in one line, with the note that explains it, its default keys and the
place of those keys in **Settings → Keybindings** (the *Section* column: the group the action is listed in there; use it to
find the row and change the key). Keys written as `Ctrl+X` are Ctrl on Linux and Windows and Cmd on macOS; where macOS has other
keys the row says so (the app menu and the system keep Cmd+H, Option+arrows and Option+letters, see [[Keyboard shortcuts]]).
**fixed** means the keys are built in and cannot be changed: text editing, vim-style editing and the drawing tools. A key
written `j` is the bare letter; `Space f f` is three keys one after the other. The full tables of keys are in [[Keyboard shortcuts]],
the settings themselves in [[Settings reference]].
