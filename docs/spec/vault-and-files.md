## Data usage and caches (USE)

What Shale keeps on disk, and the caches it may throw away (raba/shale#51).
A **cache** is a file Shale can build again from other data or fetch again; everything else
("saved data") is never deleted by anything in this section. Code goes into the feature folder
`src/data_usage/` (scan, caches, cleanup, dialog); each cache's clear and prune routine lives in
the module that owns the cache.
