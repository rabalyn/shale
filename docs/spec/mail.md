# Mail specs (MAIL)

**IS NOW** = true today (⚠ = known gap) · **SHOULD BE** = agreed target.
Tests are named `file.rs::test_fn`. QRESYNC and IDLE are not implemented in 1a (MAIL-035 uses CONDSTORE plus `UID SEARCH ALL`). Format: [ADR-0001](../decisions/0001-spec-driven-development.md). Decision: [ADR-0007](../decisions/0007-mail-client.md).
Phase 1a covers the store, the read-only sync and their tests. Phase 1b (MAIL-040…) is the mail window: account settings, the mail view, search and "Import to vault". Phase 1c (MAIL-080…092) adds the OAuth2 sign-in and the local container test environment. Phase 2 (MAIL-100…) adds flags, move and delete: **sync never writes to a server; only the explicit user actions of MAIL-102…MAIL-111 do** ([ADR-0009](../decisions/0009-mail-server-writes.md)).
