# Mail specs (MAIL)

**IS NOW** = true today (⚠ = known gap) · **SHOULD BE** = agreed target.
Tests are named `file.rs::test_fn`. QRESYNC is not implemented (MAIL-035 uses CONDSTORE plus `UID SEARCH ALL`); IDLE is used only to watch the open folder and the Inboxes (MAIL-230…MAIL-234), the sync itself does not use it. Format: [ADR-0001](../decisions/0001-spec-driven-development.md). Decision: [ADR-0007](../decisions/0007-mail-client.md).
Phase 1a covers the store, the read-only sync and their tests. Phase 1b (MAIL-040…) is the mail window: account settings, the mail view, search and "Import to vault". Phase 1c (MAIL-080…092) adds the OAuth2 sign-in and the local container test environment. Phase 2 (MAIL-100…) adds flags, move and delete: **sync never writes to a server; only the explicit user actions of MAIL-102…MAIL-111 do** ([ADR-0009](../decisions/0009-mail-server-writes.md)). Phase 3 (MAIL-120…) writes and sends mail over SMTP ([ADR-0010](../decisions/0010-sending-mail.md)). Phase 4 (MAIL-170…) verifies, decrypts, signs and encrypts with the system's GnuPG ([ADR-0011](../decisions/0011-mail-encryption.md)).

## Signing and encrypting (MAIL-17x to MAIL-19x, phase 4)

Decision: [ADR-0011](../decisions/0011-mail-encryption.md). GnuPG is the key store: `gpg` for OpenPGP, `gpgsm` for S/MIME, one shared `gpg-agent` and pinentry. Tests use a temp `GNUPGHOME` with generated, unprotected keys (loopback pinentry in tests only). S/MIME tests use self-signed certificates that are put in `trustlist.txt`; `gpgsm` signs them with any dates it is given, so expired certificates are tested (`gen_smime_valid`), and a CA made with `openssl` (`TestCa`: public certificates imported, signatures made by `openssl cms`, no PKCS#12) with a CRL loaded offline into the home's `dirmngr` (issuer-based CRL check, no network) tests chains and revoked S/MIME certificates (`gpgsm` reports a revoked certificate as a good signature followed by `TRUST_NEVER 94`, which is read as revoked); OCSP is not tested. Passphrase paths are tested with a protected key and a pinentry stub script (`TestHome::use_pinentry_stub`, Unix only).
