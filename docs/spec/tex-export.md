# Spec: PDF export through LaTeX templates (TEX)

**IS NOW** = true of the code today (⚠ = known defect) · **SHOULD BE** = agreed target.
Format: [ADR-0001](../decisions/0001-spec-driven-development.md). Decisions: [ADR-0019](../decisions/0019-latex-export-managed-texlive.md).
Umbrella issue: #277 (engine: #279, template sets: #280, writer and dialog: #281, guided setup: #282; the known gaps of the writer, closed by TEX-030 to TEX-034: #305). The built-in pure-Rust export (PDF-001…PDF-007, `src/pdf/`) stays the
default; the LaTeX path is a second engine the person picks per export (TEX-016). Tests are named
`file.rs::test_fn` (under `src/`).

## Markdown to LaTeX

The **title** of a document is the note's title: its file name without `.md` and without a leading `YYMMDD_` date prefix
(VAULT-025; a front matter `title:` replaces it). A first heading `#` that says the same is not printed again, as in the
native PDF (PDF-008). Every other heading is a heading: `#` is the first level of the body, not the title (owner decisions
#283 and #287). The writer uses `ExportOptions.toc: bool`, `ExportOptions.numbered_headings` (the vault default) and, per note,
`markdown::headings_numbered(text, opts.numbered_headings)` (PDF-008, CFG-042). Tests are in `pdf/tex/writer_tests.rs`;
`pdf/tex/writer_env_tests.rs` compiles them (TEX-019).
