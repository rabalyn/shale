# Spec: the file and folder picker (PICK)

**IS NOW** = true of the code today (⚠ = known defect) · **SHOULD BE** = agreed target.
Format: [ADR-0001](../decisions/0001-spec-driven-development.md). Decision:
[ADR-0043](../decisions/0043-one-file-picker.md). Issues: #690 (one picker everywhere), #688 (New folder).

Every place that needs a path from the person asks one picker (`src/file_picker/`): it shows the
dialog of the system first and Shale's own picker when there is none or the person turned the system's
off. Tests are named `file.rs::test_fn` (under `src/`).
