# Spec: Updates (UPD)

**IS NOW** = true of the code today (⚠ = known defect) · **SHOULD BE** = agreed target.
Format: [ADR-0001](../decisions/0001-spec-driven-development.md). Decisions: [ADR-0023](../decisions/0023-auto-update.md), [ADR-0037](../decisions/0037-signed-release-files.md) (signed release files).
Tests are named `file.rs::test_fn` (all under `src/`). The check, the download and the install run against a pretend
GitHub on `127.0.0.1` (`update/fake_github.rs`) with real `curl`; the install of a Linux folder and of an `install.sh`
install uses the real `scripts/install.sh`. The macOS and Windows installs are tested through their plans and the
file operations on Linux; they have not been run on a real macOS or Windows (UPD-016, UPD-017). The tests of `update/` run on Linux and macOS only (they use `sh` and Unix paths; the one that runs the shipped `install.sh` runs on Linux only, which has GNU `install -D`).
