# Keymap: every shortcut on the keyboard

Shale's keyboard, drawn once for each system and each layer of modifiers: which action sits on which key, coloured by the kind
of action. The pictures are screenshots of the **Keymap** tab of the program (the keyboard icon of the ribbon, or `Ctrl+Shift+Y`,
macOS `Cmd+Shift+Y`), made with the default keys. Chips with an outline are keys you changed, paler chips are fixed keys
(text editing, vim, drawing), and a hatched red key is one the system keeps for itself.

**Interactive version**: <https://rabalyn.github.io/shale/> is the same keyboard as a web page. Choose the system, an ANSI or an ISO
keyboard and a layer, hold Ctrl, Alt, Shift or Cmd on your own keyboard to look at that layer, click a key to see everything on
it, filter the list of all shortcuts, and paste the `[keybindings]` section of your `config.toml` to see your own keys. The page is
also a download of every release (`shale-keymap-<version>.html`, it works offline). Its data is made from the program's own tables
(`src/keymap_view/export.rs`), so it cannot drift from the keys the program has.

The layers can be opened one after the other below; the user guide has the same pictures as carousels (note *Keyboard shortcuts*).
